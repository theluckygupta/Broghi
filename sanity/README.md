# Sanity Studio — stubs

This folder contains schema stubs for Sanity CMS. After I create the Sanity project and invite you, you'll be able to run `sanity init`/`sanity start` and copy these schemas into the studio.

Sanity documents included:
- contact: stores contact form submissions

Note: The actual Sanity Studio is typically created with the Sanity CLI and is meant to be in a separate project directory. I'm preparing the schema so we can wire it quickly after the Sanity project exists.
